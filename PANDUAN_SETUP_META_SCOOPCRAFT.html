Dokumen ini berisi panduan langkah demi langkah untuk mengaktifkan Use Case resmi per platform di dalam dashboard Meta for Developers agar masing-masing portal login (Instagram, Threads, Facebook) dapat beroperasi secara mandiri tanpa error "Invalid platform app" ataupun "Tidak ada ID aplikasi".

📸 1. Konfigurasi Instagram Login for Business
Wajib

Digunakan untuk mengotorisasi akun Instagram Bisnis & Kreator agar sistem dapat mempublikasikan carousel visual, gambar, dan caption secara otomatis.

  1. Buka dashboard aplikasi: https://developers.facebook.com/apps/2739900363078048/
  2. Di menu sebelah kiri, klik Use Cases (Kasus Penggunaan) > klik Add Use Case (atau Tambahkan Produk).
  3. Pilih "Instagram Login for Business" atau "Instagram" > klik Set up.
  4. Di menu Instagram > Settings / Pengaturan, masukkan URL berikut ke kolom Valid OAuth Redirect URIs:
https://scoopcraft.vercel.app/api/social-accounts/oauth/instagram/callback
http://localhost:3000/api/social-accounts/oauth/instagram/callback
  1. Klik Save Changes (Simpan Perubahan).
🧵 2. Konfigurasi Threads API
Wajib

Digunakan agar portal resmi Threads (threads.net) mengenali App ID Anda dan mengizinkan posting teks utas berita / carousel.

  1. Di menu dashboard yang sama, klik Use Cases > Add Use Case.
  2. Pilih "Threads API" (Access the Threads API) > klik Set up.
  3. Di bagian Threads > Settings, masukkan URL berikut ke kolom Redirect Callback URIs:
https://scoopcraft.vercel.app/api/social-accounts/oauth/threads/callback
http://localhost:3000/api/social-accounts/oauth/threads/callback
  1. Klik Save Changes.
📘 3. Konfigurasi Facebook Login
Wajib

Digunakan untuk mengelola postingan ke Halaman Facebook (Fanspage) bisnis.

  1. Masuk ke Use Case "Facebook Login" > Settings.
  2. Pada kolom Valid OAuth Redirect URIs, masukkan URL berikut:
https://scoopcraft.vercel.app/api/social-accounts/oauth/meta/callback
https://scoopcraft.vercel.app/api/social-accounts/oauth/facebook/callback
http://localhost:3000/api/social-accounts/oauth/meta/callback
http://localhost:3000/api/social-accounts/oauth/facebook/callback
  1. Klik Save Changes.

🚀 5. Mengubah ke Mode Live / Penambahan Akun Penguji
Tahap Akhir
  1. Cara 1: Mode Live (Untuk Semua Pengguna Publik)
    Di bagian header paling atas dashboard Meta, ubah toggle App Mode dari Development menjadi Live.
  2. Cara 2: Mode Development + Tester (Jika Masih Menunggu Review Meta)
    Jika aplikasi masih dalam status Development, akun Instagram / Threads penguji harus didaftarkan di dashboard:
    • Masuk ke menu App Roles > Roles.
    • Klik Add Instagram Testers > Masukkan username Instagram penguji (misal: ibobatsuga).
    • Buka Instagram di HP (Akun Penguji) > Settings > Website Permissions > Apps and Websites > Tester Invitations > Klik Accept.
💡 Catatan Penting: Setelah langkah 1 s/d 5 selesai, semua user di Scoopcraft dapat menghubungkan Instagram, Facebook, dan Threads mereka secara langsung melalui portal resmi masing-masing tanpa ada kendala izin.
